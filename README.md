# 📅 Plánovač – kalendár a to-do list

**Otvoriť appku:** https://wickynko.github.io/kalendar-todo/

- **Kalendár** – mesačný prehľad, úlohy na každý deň, to-do bez dátumu
- **Úlohy** – stavy (Nezačaté / Rozpracované / Hotové), priority, po termíne, body na odškrtávanie (napr. Hotový web, Telefónny web, Rezervačný systém)
- **Zoradenie** podľa dôležitosti, stavu alebo dátumu
- **Sync** medzi počítačom a mobilom cez súkromný GitHub Gist, pripojenie telefónu cez QR kód
- **Apple Kalendár** – úlohy s dátumom sa zobrazia v Kalendári na iPhone aj Macu
- Funguje ako appka na ploche iPhonu (Safari → Zdieľať → Pridať na plochu) aj offline
